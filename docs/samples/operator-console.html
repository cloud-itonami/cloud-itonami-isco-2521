Action gate (Database Administration Governor)

HARD holds cannot be overridden. The governor never applies a migration itself and never accepts a backup whose schema-version doesn't equal the target database's current version.

OpGate
:draft-migrationauto-commit unless the step list contains a destructive kind (drop-table/drop-column/truncate)
:apply-migrationALWAYS human approval · real system mutation, and HARD-blocked unless the cited backup's schema-version equals the database's current version
:tune-indexauto-commit when the database is registered and belongs to the requesting client
